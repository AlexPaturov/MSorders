# Техдолг

Список известных решений, которые стоит пересмотреть после блоков A и B.

## Блок B

1. `GetAllAsync` возвращает `ReadOnlyDictionary`, что не передаёт `totalCount`; интерфейс стоит заменить на `PagedResult<Order>` без сохранения старой сигнатуры «на всякий случай».
2. Каждый тестовый класс поднимает отдельный Postgres-контейнер; при росте числа тестов это увеличит время прогона.
3. `GlobalExceptionHandler` пока не различает типы ошибок; после блока B стоит добавить ещё несколько осознанных маппингов.
